# **Тензоры**
==**Тензоры**== - *это массивы (похож на массивы из NumPy), делящиеся на типы:*
1. **0-мерный** - *это в аналогии 0d (точка) - то есть массив состоящий из одного числа/скаляр, пример: 3; 4; 12 312. (все они не зависимы от друга)*
2. **1-мерный** - *это как 1d (абсцисс / ось x) - то есть массив состоящий из чисел, которые идут слева на право, вектор (аналог простого списка в Py), пример:* [1, 2, 3, 11].
3. **2-мерный** - *это как 2d  (абсцисс и ординат / ось x и y) - то есть массив состоящий из чисел, которые аналогична таблице из строк и столбцов (матрица), пример:*$$\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$$
```Python
   [
   [ 1, 3, 5 ], 
   [ 23, 13, 44 ],
   [ 32, 22, 11 ]
   ]
```
   [ [ 1,2 ] [ 3, 4 ] ]
4. **3-мерный** - *это как 3d (ось x, y и z) - то есть массив состоящий из чисел, как бы это массив в массиве в массиве*: 
   
   [ [ [ числа 1 мерный массив ], [ числа 1 мерный массив  ] ], 
   [ [ числа 1 мерный массив ], [ числа 1 мерный массив ] ] ] 
   
   *пример:*
```python
    tensor_3d = torch.tensor ([
    [
        [3, 3, 3], 
        [4, 4, 4]
    ],
    [
        [4, 6, 7], 
        [34, 124, 4]
    ]
 ])
```
 5. **4-мерный тензор (4D)** - *можно представить как линию, состоящую из 3D-кубиков. Хорошая аналогия - это обычная книжная полка, на которой в один ряд стоят "трехмерные" книги.*
    Чтобы найти конкретное число в таком массиве, понадобятся четыре координаты:
    [номер книги на полке, страница в этой книге, строка на странице, список из символов (слово)]. 
    
    В сфере искусственного интеллекта 4D-тензоры используются постоянно, например, для передачи пакета (батча) из нескольких цветных картинок в нейросеть.

	**5-мерный тензор (5D)** - *это уже целая плоская таблица, состоящая из 3D-кубиков. В жизни это напоминает большой книжный шкаф, где книги распределены не в один ряд, а стоят на разных полках (высота) и в разных секциях (ширина).*
	 Здесь для поиска нужного элемента требуется пять координат: 
	 [номер полки, номер книги на этой полке, страница, список из символов].
	 
	  В искусственном интеллекте в виде 5D-тензоров обычно хранятся пакеты видеороликов, где осями выступают количество видео, кадры во времени, цвет, высота и ширина кадра.

	**6-мерный тензор (6D)** *представляет собой огромный трехмерный супер-куб, собранный из маленьких 3D-кубиков. Ближайшая аналогия из реального мира - это целая библиотека со множеством комнат и шкафов.*
	 В данном случае система координат разрастается до шести значений: 
	 [номер ряда шкафов, номер конкретного шкафа в этом ряду, номер полки, номер книги, страница, список из символов]

### **Инициализация**

`torch.tensor(data, dtype=..., device=..., requires_grad=..., pin_memory=...)`

`x = torch.tensor([1, 2, 3], dtype=torch.int32)`

#### **Умножение**
###### **Матричное умножение**

**`torch.matmul`** (сокращение от *matrix multiplication*) - *функция, которая выполняет матричное умножение 2-ух тензоров.*
`@` - *используют чаще этот знак.*

`torch.matmul(a, b):`
**a - первая матрица(левый операнд), b - вторая матрица (правый операнд)**

***Секретный параметр `out`:***  на самом деле он не какой не секретный, просто его редко используют. **Out** - *это необязательный третий параметр* ( `torch.matmul(a, b, out)` ) *он присваивает тензору результат **Матричного умножения.** Тензор к которому мы хотим присвоить результат должен быть создан, должен иметь идеальный итоговый размер* (`torch.matmul(a, b, out=result_tensor)` - где `a` и `b` операнды, a result_tensor, заранее созданный пустой тензор, идеальных размеров). *Когда мы передаем* `out`, *то мы обязательно должны явно указывать имя этого параметра.* (В реальном коде `out` используют для оптимизации, когда борются за каждую миллисекунду скорости работы нейросети. Когда мы присваиваем результат в переменную ( `С = torch.matmul(A, B)` ), так требуется больше памяти, больше времени (для выделения памяти)).
###### Правила

> [! ] 1. Главное правило размерностей (Совместимость)
> 
> 
> Чтобы матрицы $A$ и $B$ можно было перемножить ($A @ B$), **количество столбцов первой матрицы должно быть строго равно количеству строк второй**.
> 
> - Размер матрицы $A$: $[M \times \mathbf{N}]$
>     
> - Размер матрицы $B$: $[\mathbf{N} \times K]$
>     
> 
>   
>   **Размер результата: $[M \times K]$**
>     
> 
> > Внутренние индексы должно совпадать ($N = N$), а внешние ($M$ и $K$) задают итоговый размер.


пример ситуации:
```Python
a = torch.tensor([[1, 2, 3], [3, 3, 3]])  
b = torch.tensor([[1, 2, 3], [2, 1, 2]])  
c = a @ b  
print(c)
```
В такой ситуации выведет ошибку: 
```
Traceback (most recent call last):
  File "D:\Python\PythonPyTorch\main.py", line 16, in <module>
    c = a @ b
        ~~^~~
RuntimeError: mat1 and mat2 shapes cannot be multiplied (2x3 and 2x3)
```

Тензор `a` имеет размерность (2 *:`M`*, 3 *:`N`*), тензор `b` имеет размерность (2 *:`N`*, 3 *:`K`*), где
=> **N** у тензора `a` = 3, а **N** у тензора `b` = 2, что нарушает правило, для решения мы должны перевернуть второй тензор (`b`) использовав:
```Python
A.T             # Быстро перевернуть 2D-матрицу (строки становятся столбцами)
A.t()           # Полный аналог свойства .T, работает только для 2D
A.permute(1, 0) # Универсальный метод. Меняет оси местами вручную (для 2D, 3D, 4D и т.д.)
```
---


```Python
a = torch.tensor([[1, 2, 3], [3, 3, 3]])  
b = torch.tensor([[1, 2, 3], [2, 1, 2]])  
c = a @ b.permute(1, 0)  # или b.T или b.t()  
print(c)
```
Вывод:
```
tensor([[14, 10],
        [18, 15]])
```

> [!NOTE] 2. Порядок имеет значение (Некоммутативность)
> В отличие от обычных чисел, при умножении матриц порядок менять нельзя:
> 
> $$A \times B \neq B \times A$$
> 
> - Даже если оба умножения возможны, результаты будут совершенно разными.
>     
> - Часто при смене порядка ($B @ A$) PyTorch просто выдаст ошибку размерности.

пример ситуации 

```Python
import torch  
  
a = torch.tensor([[1, 2], [3, 4]])  
b = torch.tensor([[5, 6], [7, 8]])  
print(f"a @ b = {a @ b}")  
print(f"b @ a = {b @ a}")
```
Вывод:
```
a @ b = tensor([[19, 22],
        [43, 50]])
b @ a = tensor([[23, 34],
        [31, 46]])
```

> [!NOTE] 3. Как читать код: `@` против `*`
>  
> В PyTorch и NumPy есть два принципиально разных умножения:


```Python
# 1. МАТРИЧНОЕ умножение (Строка на Столбец) - Линейная алгебра
# Размеры ДОЛЖНЫ быть: [M x N] @ [N x K] -> Результат: [M x K]
result = A @ B  # или torch.matmul(A, B)
 
# 2. ПОЭЛЕМЕНТНОЕ умножение (Ячейка на Ячейку) - Математическая сетка
# Размеры ДОЛЖНЫ полностью совпадать: [M x N] * [M x N] -> Результат: [M x N]
result = A * B  # или torch.mul(A, B)
```

**`torch.mm`** (matrix-matrix) - *похож на `torch.matmul`* ( `torch.mm(a, b, out)` `# out не обязателен`) *их разница в том, что `torch.mm` только 2D-матрицы на 2D-матрицы, с другими размерностями (1D, 3D) вызовет ошибку, но она экономит память, т.к. это строгая прямолинейная функция, которая не растягивает матрицы под размерность, как это делает  `torch.matmul`.* **Пример:**

```Python
import torch  
  
tensor1 = torch.rand(2, 3)  
tensor2 = torch.rand(3, 3, 2)  
  
print("Result matmul: \n", torch.matmul(tensor1, tensor2))  # Выполнится
print("Result mm: \n", torch.mm(tensor1, tensor2)) # Ошибка!
```


**`torch.bmm()`** - *(**Batch Matrix-Matrix multiplication** (Пакетное матрично-матричное умножение (это уже комбо из mm() и matmul())) - это когда мы хотим умножить трёх мерные матрицы (**ТОЛЬКО 3D на 3D!**). **Параметры на вход:** точно такие же, как у прошлых функций — `a`, `b` и необязательный `out`.* 

`tensor(a, m, n)` и `tensor(a, n, k)`: 

- **`torch.bmm`** *требует, чтобы размер батча `a` был **строго равен** размеру батча второго тензора* (`a == a`)
- **`torch.matmul` (знак `@`)** - *где* `a == 1` *(у одного или сразу у всех) или* `a == a`
- `n == n` **Всегда!!**
- Будущая размерность, при `a == a` (`tensor(a, m, n)` и `tensor(a, n, k)` ): 
  `tensor(a, m, k)`, пример: 
```Python
import torch  
  
tensor1 = torch.rand(3, 5, 4) # a = 3; m = 5; n = 4 
tensor2 = torch.rand(3, 4, 2) # a = 3; n = 4; k = 2
  
print("Result size: \n", torch.bmm(tensor1, tensor2).shape) # Size(3, 5, 2)
```
**Вывод:**
```
Result size: 
 torch.Size([3, 5, 2])
```
- Будущая размерность, при (одна из) `a == 1` (`tensor(1, m, n)` и `tensor(a, n, k)` ): `tensor(a, m, k)`, пример:
```Python
import torch
```

**Вывод:**

`einsum` (**Einstein Summation**) — *это способ манипуляции тензорами, основанный на их индексах (осях), а не на названиях конкретных функций (вроде `matmul` или `transpose`). Это универсальный синтаксис, который описывает, **что происходит с осями**, а не как именно их перемножать.* 
***Пример:***

**запись:**
`torch.einsum('ji, ia -> ja', A, B)` *# тут простое матричное умножение*

```

```

#### **Ручной расчет градиентов vs PyTorch**

**Задача:** Найти значение функции $y$ и градиенты (производные) для тензора $x = [2.0, 3.0]$ вручную, а затем проверить через PyTorch.

**Формула функции ошибки (Loss):**

$$y = \frac{1}{|x|} \sum_{i} (2 \cdot x_i^2 - 1)$$

_Так как в тензоре 2 элемента, $\frac{1}{|x|}$ превращается в $\frac{1}{2}$ (поиск среднего арифметического)._

##### Часть 1: Нахождение финального $y$

Подставляем $x_1 = 2$ и $x_2 = 3$ в формулу:

- Для $x_1 = 2 \rightarrow 2 \cdot (2^2) - 1 = 7$
    
- Для $x_2 = 3 \rightarrow 2 \cdot (3^2) - 1 = 17$
    
- Находим среднее:
    
    $$y = \frac{7 + 17}{2} = 12.0$$
    

#####  Часть 2: Вывод формулы градиента (Работа над ошибками)

	Константу (число) можно просто выносить за знак производной и не трогать её

##### Элегантное решение (Раскрытие скобок):

##### Часть 3: Расчет точных значений градиента

#####  Часть 4: Проверка кодом в PyTorch

```Python
import torch

# 1. Создаем тензор и включаем слежку
x = torch.tensor([2.0, 3.0], requires_grad=True)

# 2. Задаем граф вычислений (нашу формулу)
y = (2 * x**2 - 1).mean()

y.backward()

```

## **Параметры нейросети** и *работа ИИ*
**Классификация** *(когда ИИ выбирает категорию, например: «кошка» или «собака»).*
**Регрессия** *(когда ИИ должен предсказать конкретное непрерывное число - цену квартиры, температуру, курс доллара).*
### **Параметры нейросети**

==**Входные данные**== *(Inputs / $X$)* - *вектор или тензор признаков (features), представляющий собой закодированную в цифровой вид информацию, которая подается на первый (входной) слой нейронной сети для последующих линейных и нелинейных преобразований.*

---

==**Веса ($w$)**== (***это главный регулируемый параметр нейросети***) - *это обучаемые (изменяемые) параметры нейросети, которые показывают (определяют), насколько сильно факт влияет на итоговый ответ. Грубо говоря **весы (w)** - это коэффициент того на сколько сильно факт влияет на итоговый ответ иишки ответ, пример:*
у нас есть квартира, которую мы хотим купить, на ее цену влияют:
- **размер (в Кв. м)** *(120 000)*
- **расстояние от центра города** *(-30 000)*
- **этаж** *(0)*  "*нейросеть в процессе обучения поняла, что ей это не нужно, как фактор цены*"

>*цифра и есть коэффициент (вес)*
> 	То есть на цену квартиры (как не странно) сильнее всего влияет её **размер**,
> 	в свою очередь, этаж не так сильно (меньше всего).

Типы весов: активирующий (положительный) или тормозящий (отрицательный). *Положительный (в примере) увеличивает цену, отрицательный уменьшаеь.*

==**Важность признаков== (Feature Importance)** - *это то насколько факт важен для модели (ии). Важно, после обучения!* 
- **размер (в Кв. м)** *(90%)*
- **расстояние от центра города** *(8%)*
- **этаж** *(2%)*
>это то что нам помогло понять (подобрать) итоговую сумму.

==**Расчет весов**==
$$k = \frac{1}{\sqrt{\text{ВХОДЫ}}}$$
выше  расчет весов, который записывается в $$\text{Диапазон весов} = \left[ -k; \; +k \right]$$
если мы пишем нейросеть для поиска квартиры, то в начале обучения ответы ии будут рандомными, но после обучения, ии изменит веса (которые были +- 0-1) до n-ого - нужного нам числа для формул.


---

**Смещение *(Bias/$b$)*** - *(такая же начальная формула) это свободный член (интерцепт) в уравнении линейного преобразования слоя нейронной сети ($y = wx + b$). Простым языком, это начальный капитал, который прибавляется к выходному ответу, для избежание 0 в ответах при входные данных ($X = 0$) равным нулю.*

У каждого **нейрона**: сво**и** веса (много) и сво**ё** смещение (одно число). У каждого **слоя** нейросети: своя **матрица** весов и свой **вектор** смещений.
